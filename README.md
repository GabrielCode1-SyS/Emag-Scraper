# Python Web Scraper

A simple web scraper made with Python that extracts product information from a website using Requests and BeautifulSoup.

## Features

* Extracts product prices
* Extracts product ratings
* Extracts stock availability
* Uses BeautifulSoup for HTML parsing
* Uses OOP to store extracted data

## Technologies

* Python
* Requests
* BeautifulSoup4

## Installation

Install the required libraries:

```bash
pip install requests beautifulsoup4 html5lib
```

## Usage

Run the script:

```bash
python scraper.py
```

The scraper will collect the information from the website and display the results.

## Purpose

I created this project to practice web scraping, HTTP requests, HTML parsing, and Python OOP.
